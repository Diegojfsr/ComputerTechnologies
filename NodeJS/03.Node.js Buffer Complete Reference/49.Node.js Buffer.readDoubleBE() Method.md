O método Buffer.readDoubleBE() no Node.js é usado para ler um double de 64 bits do buffer no deslocamento fornecido com o formato Big Endian. 
Sintaxe:
```
Buffer.readDoubleBE( offset )
```

Parâmetros: Esse método aceita um único parâmetro offset, que contém o número de bytes a serem ignorados antes de iniciar a leitura. O valor de offset está entre 0 <= offset <= buf.length - 8. Seu valor padrão é 0. Valor de retorno: Retorna um valor inteiro no formato big endian. Os exemplos abaixo ilustram o uso do método buf.readDoubleBE() no Node.js: 
### Exemplo 1:
```node
// Node program to demonstrate the  
// Buffer.readDoubleBE() method 

// Creating a buffer of given size 
const buf = Buffer.from([10, 20, 30, 40, 50, 60, 70, 80]);

// Display the result 
console.log("Functions of Buffer.readDoubleBe(int)");
console.log(buf.readDoubleBE(0))
console.log(buf);
```
Saída:
```
Functions of Buffer.readDoubleBe(int)
4.0888790063059496e-260
<Buffer 0a 14 1e 28 32 3c 46 50>
```
