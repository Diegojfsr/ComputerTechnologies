O método Buffer.writeInt16LE() é uma interface de programação de aplicativo embutida da classe Buffer dentro do módulo Buffer que é usada para gravar um inteiro de 16 bits assinado válido no buffer no deslocamento especificado com o formato little endian especificado. 
Sintaxe:
```
Buffer.writeInt16LE( value, offset )
```

Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito abaixo:
value: O número inteiro de 16 bits assinado válido a ser gravado no buffer.
offset: Indica o número de bytes a serem ignorados antes de iniciar a gravação no buffer. O valor de offset está dentro do intervalo 0 <= offset <= buf.length - 2. O valor padrão de offset é 0.

Valor de retorno: Retorna um buffer com o valor inserido no deslocamento especificado no formato little endian. Os exemplos a seguir ilustram o uso do método Buffer.writeInt16LE() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the 
// Buffer.writeInt16LE() method 
    
// Creating a buffer 
const buf = Buffer.allocUnsafe(10); 

// Using Buffer.writeInt16LE() method 
buf.writeInt16LE(0x0114, 0); 

// Display the buffer 
console.log(buf); 

// Using Buffer.writeInt16LE() method 
buf.writeInt16LE(0x1015, 2); 

// Display the buffer 
console.log(buf); 

// Using Buffer.writeInt16LE() method 
buf.writeInt16LE(0x0016, 8); 

// Display the buffer 
console.log(buf); 

// Using Buffer.writeInt16LE() method 
buf.writeInt16LE(0x0217, 6); 

// Display the buffer 
console.log(buf); 

// Using Buffer.writeInt16LE() method 
buf.writeInt16LE(0x0518, 4); 
    
// Display the result 
console.log(buf);
```
Saída:
```
<Buffer 14 01 9b 02 00 00 00 00 a8 79>
<Buffer 14 01 15 10 00 00 00 00 a8 79>
<Buffer 14 01 15 10 00 00 00 00 16 00>
<Buffer 14 01 15 10 00 00 17 02 16 00>
<Buffer 14 01 15 10 18 05 17 02 16 00>
```
