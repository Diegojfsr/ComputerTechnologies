O método Buffer.writeInt32BE() é uma interface de programação de aplicativo embutida da classe Buffer dentro do módulo Buffer, que é usada para gravar um valor inteiro no buffer no deslocamento especificado com o formato big-endian; o valor inteiro deve ser um inteiro de 32 bits assinado válido. O valor inteiro é interpretado e gravado como um inteiro assinado de complemento de dois. 
Sintaxe:
```
Buffer.writeInt32BE( value, offset )
```

Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito abaixo: value (valor): Esse parâmetro contém um número inteiro assinado de 32 bits que precisa ser gravado no buffer. offset: Esse parâmetro contém um valor inteiro, ou seja, o número de bytes a serem ignorados antes de começar a gravar no buffer. O valor de offset está entre 0 e buf.length - 4. É um parâmetro opcional e seu valor padrão é 0. Valor de retorno: Esse método retorna um valor inteiro, ou seja, a soma do deslocamento mais o número de bytes gravados. Os exemplos abaixo ilustram o uso do método buf.writeInt32BE() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the  
// Buffer.writeInt32BE() Method

// Allocating buffer space of 4 bytes
const buf = Buffer.allocUnsafe(4);

// Writing the value to the buffer
buf.writeInt32BE(0x7bcaf892);

// Display the buffer to stdout
console.log(buf);
```
Saída:
```
<Buffer 7b ca f8 92>
```

### Exemplo 2:
```node
// Node.js program to demonstrate the  
// Buffer.writeInt32BE() Method

// Allocating buffer space of 8 bytes
const buf = Buffer.allocUnsafe(8);
 
// Writing the value to the buffer from 0 offset
buf.writeInt32BE(0x7bcaf983, 0);

// Writing the value to the buffer from 4 offset
buf.writeInt32BE(0x7fffffff, 4);
 
// Display the buffer to stdout
console.log(buf);
```
Saída:
```
<Buffer 7b ca f9 83 7f ff ff ff>
```

### Exemplo 3:

// Node.js program to demonstrate the
