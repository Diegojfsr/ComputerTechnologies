O método Buffer.readInt16BE() é uma interface de programação de aplicativo embutida da classe Buffer no módulo Buffer que lê um inteiro assinado de 16 bits do buffer no deslocamento especificado no formato big endian. 
Sintaxe:
```
Buffer.readInt16BE( offset )
```

Parâmetros: Esse método aceita um único parâmetro offset, que especifica o número (inteiro) de bytes a serem ignorados antes de iniciar a gravação. O valor de offset está dentro do intervalo 0 <= offset <= buf.length - 2. Seu valor padrão é zero. Valor de retorno: Retorna o deslocamento junto com o número de bytes gravados. 
### Exemplo 1:
```node
// Node.js program to demonstrate the   
// Buffer.readInt16BE() method  

// Create a buffer 
const buf = Buffer.from([0, 3]);

// Display the result
console.log(buf.readInt16BE(0));
```
Saída:
```
3
```
