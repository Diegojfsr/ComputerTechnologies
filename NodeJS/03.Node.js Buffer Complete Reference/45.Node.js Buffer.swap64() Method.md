O método Buffer.swap64() é uma interface de programação de aplicativo embutida da classe Buffer dentro do módulo Buffer que é usada para trocar a ordem de bytes do buffer no local. A troca é realizada pela interpretação do buffer como uma matriz de números de 64 bits. 
Sintaxe:
```
Buffer.swap64()
```

Parâmetros: Esse método não aceita nenhum parâmetro. Valor de retorno: Retorna a referência ao buffer. Erro lançado: lança ERR_INVALID_BUFFER_SIZE se o comprimento do buffer (buf.length) não for um múltiplo de 8. Os exemplos abaixo ilustram o uso do método Buffer.swap64() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the 
// Buffer.swap64() method 
    
// Creating a buffer 
const buf = Buffer.from([0x7, 0x0, 0x1,
              0x1, 0x4, 0x5, 0x4, 0x6]); 

// Display the buffer value
// before swap 
console.log(buf); 

// Using Buffer.swap64() method
buf.swap64();
    
// Display the result 
// after swap
console.log(buf);
```
Saída:
```
<Buffer 07 00 01 01 04 05 04 06>
<Buffer 06 04 05 04 01 01 00 07>
```

### Exemplo 2: 
Veremos o erro lançado por esse método
```node
// Node.js program to demonstrate the 
// Buffer.swap64() method 
    
// Creating a buffer 
const buf = Buffer.from([0x0,
         0x1, 0x2, 0x3, 0x4, 0x5]); 

// Display the buffer value
// before swap 
console.log(buf); 

try {
    // Using Buffer.swap64() method
    // It will throw error
    buf.swap64();

    // Display the result 
    // after swap
    console.log(buf);
}
catch(e) {
    console.log("Entering catch block");

    // Display error
    console.log(e);
}
```
Saída:
```
<Buffer 00 01 02 03 04 05>
Entering catch block
RangeError [ERR_INVALID_BUFFER_SIZE]: Buffer size must be a multiple of 64-bits
    at Buffer.swap64 (buffer.js:1059:11)
    at /home/runner/index.js:14:9
    .......
```

Observação: o programa acima será compilado e executado usando o comando node index.js. Referência: https://nodejs.org/dist/latest-v13.x/docs/api/buffer.html#buffer_buf_swap64
