O método Buffer.writeInt16BE() é uma interface de programação de aplicativo embutida da classe Buffer dentro do módulo Buffer que é usada para gravar um valor inteiro no buffer no deslocamento especificado com o formato big-endian. O valor inteiro deve ser um número inteiro de 16 bits assinado válido. O erro será lançado se o valor estiver fora do intervalo do inteiro de 16 bits assinado. O valor inteiro é interpretado e gravado como um inteiro assinado de complemento de dois. 
Sintaxe:
```
Buffer.writeInt16BE( value, offset )
```

Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito abaixo:
value (valor): É um número inteiro assinado de 16 bits que deve ser gravado no buffer.
offset: É um valor inteiro, ou seja, o número de bytes a serem ignorados antes de começar a gravar no buffer. O valor de offset varia de 0 a buf.length-2. É um parâmetro opcional e seu valor padrão é 0.

Valor de retorno: Ele retorna um valor inteiro que é a soma do deslocamento mais o número de bytes gravados. Os exemplos abaixo ilustram o uso do método buf.writeInt16BE() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the   
// Buffer.writeInt16BE() Method 
  
// Allocate a buffer
const buf = Buffer.allocUnsafe(2);

// Writing the value to the buffer
buf.writeInt16BE(0x7bca);

// Display the buffer value
console.log(buf);
```
Saída:
```
<Buffer 7b ca>
```

### Exemplo 2:
```node
// Node.js program to demonstrate the   
// Buffer.writeInt16BE() Method 
  
// Allocate a buffer
const buf = Buffer.allocUnsafe(4);

// Writing the value to the buffer
// from 0 offset
buf.writeInt16BE(0x7bca, 0);

// Writing the value to the buffer
// from 2 offset
buf.writeInt16BE(0x7fff, 2);

// Display the result
console.log(buf);
```
Saída:
```
<Buffer 7b ca 7f ff>
```
