A propriedade Buffer.buffer é uma interface de programação de aplicativo embutida da classe Buffer no módulo buffer, que é usada para obter o objeto do buffer de matriz equivalente a esse objeto buffer.
Sintaxe:
```
const buf.buffer
```

Valor de retorno: Essa propriedade retorna o objeto do buffer de matriz.

### Exemplo 1: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// Buffer.buffer property

// Creating a Buffer
const buff = Buffer.from([1, 2, 3, 4, 5]);

// Getting the value of array buffer
const value = buff.buffer;

// Display the result
console.log("Big Integer :- " + value);
```
Saída:
```
Big Integer :- [object ArrayBuffer]
```

### Exemplo 2: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// Buffer.buffer property

// Creating and initializing arraybuffer object
const arrbuff = new ArrayBuffer(16);

// Getting buffer object form existing 
// arraybuffer object
const buffer = Buffer.from(arrbuff);

// Display the result
if(buffer.buffer === arrbuff)
    console.log("both buffer is equivalent");
else
    console.log("both buffer is not equivalent");
```
Saída:
```
both buffer is equivalent
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```
