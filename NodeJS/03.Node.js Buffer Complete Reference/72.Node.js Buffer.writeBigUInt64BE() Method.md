O método Buffer.writeBigUInt64BE() é uma interface de programação de aplicativo embutida da classe Buffer dentro do módulo Buffer, que é usada para gravar um valor Big Integer de 64 bits big endian em um buffer alocado no deslocamento especificado.
Sintaxe:
```
Buffer.writeBigUInt64BE( value, offset )
```

Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito abaixo:

value (valor): Esse parâmetro especifica o valor inteiro grande a ser gravado no buffer. Deve ser um valor válido de 64 bits big endian Big integer. O comportamento é indefinido quando o valor é diferente desse.
offset: Especifica o número de bytes a serem ignorados antes da gravação ou simplesmente indica o índice no buffer. O valor de offset é 0 <= offset <= Buffer.length - 8. Seu valor padrão é 0.

Valor de retorno: Esse método retorna um valor inteiro sem sinal que é a soma do deslocamento e do número de bytes gravados.
Os exemplos abaixo ilustram o uso do método Buffer.writeBigUInt64BE() no Node.js:
### Exemplo 1:
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// buffer.writeBigUInt64BE() method 
const buf = Buffer.allocUnsafe(8);

// Writing big integer value into buffer
// by using writeBigUInt64BE() method
buf.writeBigUInt64BE(0x01030405060708n, 0);

// Display the buffer
console.log(buf);
```

Execute o arquivo index.js "
usando o seguinte comando:
```
node index.js
```
Saída:
```
<Buffer 00 01 03 04 05 06 07 08>
```
