A propriedade Buffer.length é uma interface de programação de aplicativo embutida da classe Buffer dentro do módulo buffer, que é usada para obter o comprimento desse objeto buffer.
Sintaxe:
```
const Buffer.length
```

Parâmetros: Essa propriedade não aceita nenhum parâmetro.
Valor de retorno: Essa propriedade retorna o comprimento desse objeto de buffer.

### Exemplo 1: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// Buffer.length property

// Creating and initializing arraybuffer object
const arrbuff = new ArrayBuffer(16);

// Getting buffer object from existing
// arraybuffer object
const buffer = Buffer.from(arrbuff);

// Getting length of buffer
// by using length property
const length = buffer.length;

// Display the result
console.log("Length is : " + length);
```
Saída:
```
Length is : 16
```
