O método Buffer.readBigInt64BE() é usado para ler um inteiro grande de 64 bits de um objeto buffer em um determinado deslocamento e retorna o resultado em Big endian.
Sintaxe:
```
buffer.readBigInt64BE( offset )
```

Parâmetros: Esse método aceita um único parâmetro offset que especifica a posição do objeto de buffer. Ele representa o número de bytes a serem ignorados antes de iniciar a leitura. O valor de offset está dentro do intervalo de 0 a buffer.length - 8. O valor padrão é 0.
Valor de retorno: Esse método lê um inteiro grande de 64 bits assinado no deslocamento especificado em Big endian.
### Exemplo 1: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// buffer.readBigInt64BE() method 
const buff = Buffer.from([0x00, 0x00, 
    0x00, 0x00, 0xff, 0xff, 0xff, 0xff]);

// Getting big integer value by
// using readBigInt64BE method
const value = buff.readBigInt64BE(0);

// Display the result
console.log("Big Integer :- " + value);
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```
Saída:
```
Big Integer :- 4294967295
```
