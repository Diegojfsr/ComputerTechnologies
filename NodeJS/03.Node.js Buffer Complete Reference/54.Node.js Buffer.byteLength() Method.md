O método Buffer.readDoubleLE() no Node.js é usado para ler um double de 64 bits do buffer no deslocamento fornecido com o formato Little Endian. 
Sintaxe:
```
Buffer.readDoubleLE( offset )
```

Parâmetros: Esse método aceita um único parâmetro offset, que contém o número de bytes a serem ignorados antes de iniciar a leitura. O valor de offset está entre 0 <= offset <= buf.length - 8. Seu valor padrão é 0. Valor de retorno: Retorna um valor inteiro no formato little endian. Os exemplos abaixo ilustram o uso do método buf.readDoubleLE() no Node.js: 
### Exemplo 1:
```node
// Node program to demonstrate the
// Buffer.readDoubleLE() method

// Creating a buffer of given size
const buf = Buffer.from([1, 2, 3, 4, 5, 6, 7, 8]);

// Display the result
console.log(buf.readDoubleLE(0));
console.log(buf);
```
Saída:
```
5.447603722011605e-270
<Buffer 01 02 03 04 05 06 07 08>
```
