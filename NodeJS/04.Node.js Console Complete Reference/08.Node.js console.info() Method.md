O método console.info() é uma interface de programação de aplicativo incorporada do módulo de console que é usada para imprimir mensagens no stdout em uma nova linha. Ele é semelhante ao método console.log().
Sintaxe:
```
console.info(data, args);
```

Parâmetros: Esse método tem dois parâmetros, conforme mencionado acima e descrito abaixo:
data: Esse parâmetro especifica os dados a serem impressos.
args: É um parâmetro opcional que o especifica para ser passado como valores de substituição nas mensagens passadas para data. Todos os args passados são enviados para util.format().
Valor de retorno: Esse método não retorna nada, mas imprime a mensagem formatada no stdout em uma nova linha.

### Exemplo 1:
Os exemplos abaixo ilustram o uso do método console.info() no Node.js:
Nome do arquivo: app.js
```node
// Node.js program to demonstrate the
// console.info() method

// Accessing console module
const console = require('console');

// Calling console.info() method
console.info("this is a sample info message!");
console.info("sample info message with args: %d", 39);
```

Execute o arquivo app.js usando o seguinte comando:
```
node app.js
```
Saída:
```
this is a sample info message!
sample info message with args: 39
```

### Exemplo 2: 
Os exemplos abaixo ilustram o uso do método console.info() no Node.js:
Filename: app.js 
```node
// Node.js program to demonstrate the
// console.info() method

// Accessing console module
const console = require('console');

// Calling console.info() method
console.info("this is a %s" +
    " sample info message!");

console.info("sample info message "
    + "with args: %d", 34);
console.info("info message: Warning "
    + "at function %s: line number"
    + " %d ff()", 96)

let isDebugMode = true;
console.custom_info = function (message) {
    if (isDebugMode) {
        console.log(message);
    }
}

console.custom_info("custom info message");
```

Execute o arquivo app.js usando o seguinte comando:
```
node app.js
```
Saída:
```
this is a  sample info message!
sample info message with args: 34
info message: Warning at function ff(): line number 96
custom info message
```

Observação: o programa acima será compilado e executado usando o comando node filename.js.
Referência: https://nodejs.org/api/console.html#console_console_info_data_args
