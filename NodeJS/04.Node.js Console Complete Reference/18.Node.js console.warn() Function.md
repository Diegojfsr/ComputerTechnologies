A função console.warn() da classe console do Node.js é usada para exibir as mensagens de aviso no console. Ela imprime no stderr com nova linha. Observação: Essa função é um alias da função console.error(). 
Sintaxe:
```
console.warn( [data][, ...args] )
```

Parâmetro: Essa função pode conter vários parâmetros. O primeiro parâmetro é usado para a mensagem principal e os outros parâmetros são usados para valores de substituição. Valor de retorno: A função retorna a mensagem de aviso. Os programas abaixo demonstram o funcionamento da função console.warn(): 
### Programa 1:
```node
function displayWarning(x) {
    console.warn(`GeeksforGeeks is a ${x} portal`);
}
 
const x = 'Computer Science';

displayWarning(x);
```
Saída:
```
GeeksforGeeks is a Computer Science portal
```

### Programa 2:
```node
function compareNumber(x, y) {
    
    // Check condition
    if (x > y) {
        console.warn(`${x} is greater then ${y}`);
    }
    else {
        console.warn(`${x} is less then or equal to ${y}`);
    }
}

// Store number to variable
x = 100;
y = 50;

compareNumber(x, y);
```
Saída:
```
100 is greater then 50
```
