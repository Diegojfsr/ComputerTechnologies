O módulo de console fornece um console de depuração simples que é fornecido por navegadores da Web que exportam dois componentes específicos:
Uma classe de console que pode ser usada para gravar em qualquer fluxo do Node.js. Exemplo: console.log(), console.error(), etc.
Um console global que pode ser usado sem importar o console. Exemplo: process.stdout, process.stderr, etc.

O método console.profile() (adicionado na versão 8.0.0) é uma interface de programação de aplicativo integrada do módulo "console" que não exibe nada, a menos que seja usado no inspetor. Ele inicia um perfil de CPU JavaScript com um rótulo opcional até que console.profile() seja chamado. O perfil é então adicionado ao painel Perfil do inspetor.
Observação: Os métodos do console global não são nem consistentemente síncronos nem consistentemente assíncronos.
Sintaxe:
```
console.profile([label])
```
Parâmetros: Essa função aceita um único parâmetro, conforme mencionado acima e descrito abaixo:
label `<string>`: Aceita o nome do rótulo que será usado posteriormente no inspetor.
Valor de retorno: Não imprime nada no console; em vez disso, inicia um perfil de CPU JavaScript no Inspetor.
Os exemplos abaixo ilustram o uso de um método console.profile() no Node.js.
### Exemplo 1: Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// console.profile() Method

// Starting MyLabel console profile
console.profile('MyLabel');

// Doing some task
for (let i = 0; i < 4; i++) {

    // Printing some task
    console.log('Doing task no:', i);
}

// Finishing MyLabel profile
console.profileEnd('MyLabel');
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```

Saída no console:
```
Doing task no: 0
Doing task no: 1
Doing task no: 2
Doing task no: 3
```

### Exemplo 2: Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// console.profile() Method

// New profile function
function newProfile(callback) {
    try {
        // Doing some task
        for (let i = 1; i < 4; i++) {
            console.log('Working on task:', i);
            callback();
        }
    } catch {

        // Prints if there is error
        console.error('error occurred');
    }
}

// Starting newProfile() console profile
console.profile("newProfile()");

// Calling newprofile()
newProfile(function alfa() {

    // Finishing profile
    console.profileEnd();
});
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```

Saída no console:
```
Working on task: 1
Working on task: 2
Working on task: 3
```
