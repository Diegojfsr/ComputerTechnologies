O método console.count() é uma interface de programação de aplicativo embutida do módulo de console que é usada para contar o rótulo passado a ele como parâmetro, mantendo um contador interno para esse rótulo específico. 
Sintaxe:
```
console.count(label)
```

Parâmetros: Esse método tem um parâmetro, conforme mencionado acima e descrito abaixo:
label: É um parâmetro opcional que especifica o rótulo a ser contado. O valor padrão é "default".
Valor de retorno: Esse método gera a contagem dessa função chamada com o rótulo especificado para o stdout. Os exemplos a seguir ilustram o uso do método console.count() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the   
// console.count() Method

// Accessing console module
const console = require('console');

// Calling console.count() 
console.count("a");
console.count("b");
console.count("a");
console.count("a");
console.count("a");
console.count("b");
console.count("b");
console.count("b");
```
Saída:
```
a: 1
b: 1
a: 2
a: 3
a: 4
b: 2
b: 3
b: 4
```

### Exemplo 2:
```node
// Node.js program to demonstrate the   
// console.count() Method

// Accessing console module
const console = require('console');

// Calling console.count() method
// with no parameter to count
// default label
console.count();
console.count("a");
console.count("b");
console.count("a");
console.count("a");
console.count();
console.count();
console.count();
console.count("b");
```
Saída:
```
default: 1
a: 1
b: 1
a: 2
a: 3
default: 2
default: 3
default: 4
b: 2
```

Observação: o programa acima será compilado e executado usando o comando node filename.js. Referência: https://nodejs.org/api/console.html#console_console_count_label
