O método console.trace() é uma interface de programação de aplicativo incorporada do módulo de console que é usada para imprimir mensagens de rastreamento de pilha no stderr em uma nova linha. Semelhante ao método console.error().
Sintaxe:
```
console.trace(message, args);
```

Parâmetros: Esse método tem dois parâmetros, conforme mencionado acima e descrito a seguir:
message: Esse parâmetro especifica a mensagem a ser impressa.
args: É um parâmetro opcional que especifica os parâmetros a serem passados como valores de substituição na mensagem. Todos os args passados são enviados para util.format().
Valor de retorno: Esse método não retorna nada, mas imprime a cadeia de caracteres 'Trace:' seguida da mensagem formatada para stderr em uma nova linha e o rastreamento de pilha para a posição atual no código.

Os exemplos abaixo ilustram o uso do método console.trace() no Node.js.
Nome do arquivo: app.js

```node
// console.trace() method

// Accessing console module

// Calling console.trace() method
console.trace("stack teace sample");

console.trace(
    "stack trace sample with args: %d", 39);
```

```
node app.js
```

### Exemplo 2: 
Os exemplos abaixo ilustram o uso do método console.trace() no Node.js.
Nome do arquivo: app.js
```node
// Node.js program to demonstrate the
// console.trace() method

// Accessing console module
const console = require('console');

// Calling console.trace() method
console.trace("stack trace message: "
               + "at %s: line no: %d ", "ff()", 96);

let isTrace = true;

console.custom_trace = function (message) {
    if (isTrace) {
        console.trace(message);
    }
}

console.custom_trace("custom trace message");
```

```
node app.js
```
