O método console.assert() é uma interface de programação de aplicativo embutida do módulo de console que é usada para afirmar o valor passado a ele como parâmetro, ou seja, ele verifica se o valor é verdadeiro ou não e imprime uma mensagem de erro, se for fornecido e não conseguir afirmar o valor. 
Sintaxe:
```
console.assert(value, messages)
```
Parâmetros: Esse método tem dois parâmetros, conforme mencionado acima e descrito abaixo:
value (valor): Esse parâmetro especifica o valor a ser declarado.
messages: Especifica as mensagens a serem usadas como mensagens de erro. Qualquer parâmetro passado junto com o valor será considerado como uma mensagem.

Valor de retorno: Esse método não retorna nada se o valor for verdadeiro. Se não for possível afirmar o valor, então Assertion failed será registrado seguido de uma mensagem de erro, se fornecida em todos os parâmetros subsequentes após o valor em util.format(). A saída é usada como uma mensagem de erro.

### Exemplo 1:
O exemplo abaixo ilustra o uso de um método console.assert() no Node.js
```node
// Node.js program to demonstrate the
// console.assert() Method

// Accessing console module
const console = require('console');

// Calling console.assert() method
console.assert(true, "error message 1");
console.assert(false, "error message 2");
```
Saída:
```
Assertion failed: error message 2
```

### Exemplo 2: 
O exemplo abaixo ilustra o uso de um método console.assert() no Node.js
```node
// Node.js program to demonstrate the
// console.assert() Method

// Accessing console module
const console = require('console');

// Calling console.assert()
let a = 10, b = 5;

console.assert(1 == 1, "error at 1==1");
console.assert(1 != 1, "error at 1!=1");
console.assert(3 & 9, "error at 3&9");
console.assert(1 & 6, "error at 1&6");
console.assert(0 && 9, "error at 0&&9");
console.assert(1 && 8, "error at 1&&8");
console.assert(a % b == 1, "error at a%b==1");
console.assert(a > b, "error at a>b");
console.assert(b > a, "error at b>a");
```
Saída:
```
Assertion failed: error at 1!=1
Assertion failed: error at 1&6
Assertion failed: error at 0&&9
Assertion failed: error at a%b==1
Assertion failed: error at b>a
```

Observação: o programa acima será compilado e executado usando o comando node filename.js.
