O módulo de console fornece um console de depuração simples que é fornecido por navegadores da Web que exportam dois componentes específicos:
Uma classe de console que pode ser usada para gravar em qualquer fluxo do Node.js. Exemplo: console.log(), console.error(), etc.
Um console global que pode ser usado sem importar o console. Exemplo: process.stdout, process.stderr, etc.

O método console.timeStamp() (Adicionado na versão 8.0.0) é uma interface de programação de aplicativo incorporada do módulo "console" que não exibe nada, a menos que seja usado no inspetor. Esse método adiciona um evento com o rótulo "label" ao painel Linha do tempo do inspetor.
Observação: Os métodos do console global não são nem consistentemente síncronos nem consistentemente assíncronos.
Sintaxe:
```
console.timeStamp([label])
```

Parâmetros: Essa função aceita um único parâmetro, conforme mencionado acima e descrito abaixo:
label `<string>`: Aceita o nome do rótulo que será usado posteriormente no inspetor.
Valor de retorno: Não imprime nada no console, mas imprime o registro de data e hora na chamada no Inspetor.
Os exemplos abaixo ilustram o uso do método console.timeStamp() no Node.js.
### Exemplo 1: Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// console.timeStamp() Method

// Starting newProfile() console profile
console.profile("Hello()");

// Printing timestamp
console.timeStamp("Hello()");

// Finishing profile
console.profileEnd("Hello()");
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```

Saída no console:
```
*Doesn't print anything in Console...
```

### Exemplo 2: Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// console.timeStamp() Method

// Starting Hello() console profile
console.profile("Hello()");

// Printing timeStamp
console.timeStamp("Hello()");

// Performing some action
for (let i = 0; i < 1; i++) {
    console.log("doing some task...");
}

// Finishing profile
console.profileEnd("Hello()");

// Printing timeStamp again
console.timeStamp("Hello()");
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```

Saída no console:
```
Doing some task...
```
