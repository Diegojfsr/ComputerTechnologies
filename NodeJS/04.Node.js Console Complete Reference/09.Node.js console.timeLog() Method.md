O método console.timeLog() é uma função embutida no Nodejs que é usada para exibir o tempo de cada execução. Essa função é comprovadamente eficaz quando usada em um loop. 
Sintaxe:
```
console.log([label][, ...data])
```

Parâmetros: Essa função aceita dois ou mais parâmetros. Valor de retorno: Esse método exibe a hora da execução. Os exemplos a seguir ilustram o método console.timeLog() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the   
// console.timeLog() method

// Time started
console.time("executionTime");
for (let i = 0; i < 10; i++) {

    // Printing execution time for each
    console.timeLog("executionTime");
}
```

### Exemplo 2:
```node
// Node.js program to demonstrate the   
// console.timeLog() method

// Time started
console.time("totalExecutionTime");

// Time started
console.time("executionTime");

for (let i = 0; i < 10; i++) {

    // Printing execution time for each
    console.timeLog("executionTime");
}

// Printing total execution time
console.timeLog("totalExecutionTime");
```
