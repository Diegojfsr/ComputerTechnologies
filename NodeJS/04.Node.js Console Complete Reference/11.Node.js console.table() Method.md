O método console.table() é uma interface de programação de aplicativo incorporada do módulo de console que é usada para imprimir no console a tabela construída a partir de seus parâmetros. 
Sintaxe:
```
console.table(data, properties);
```
Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito abaixo:
data: Dados tabulares. Uma matriz de dados de cada linha que contém valores para cada coluna dessa linha específica.
properties: Especifica as propriedades para a construção da tabela.
Valor de retorno: Esse método não retorna nada além de imprimir a tabela construída e registrá-la. Se ele não conseguir analisar os argumentos na tabela, ele simplesmente registrará os argumentos. Os exemplos abaixo ilustram o uso do método console.table() no Node.js. 
### Exemplo 1: Nome do arquivo: app.js
```node
// Node.js program to demonstrate the   
// console.table() method

// Accessing console module
const console = require('console');

// Calling console.table() 
// without construction rule
console.table([
    { a: 1, b: 2 }, 
    { a: 3, b: 7, c: 'y' }
]);

// With construction rule
console.table([
    { a: 1, b: 2 }, 
    { a: 3, b: 7, c: 'y' }],
    ["a", "b"]
);
```

Execute o arquivo app.js usando o seguinte comando:
```
node app.js
```
Saída:
```
┌─────────┬───┬───┬─────┐
│ (index) │ a │ b │ c   │
├─────────┼───┼───┼─────┤
│    0    │ 1 │ 2 │     │
│    1    │ 3 │ 7 │ 'y' │
└─────────┴───┴───┴─────┘

┌─────────┬───┬───┐
│ (index) │ a │ b │
├─────────┼───┼───┤
│    0    │ 1 │ 2 │
│    1    │ 3 │ 7 │
└─────────┴───┴───┘
```

### Exemplo 2: Nome do arquivo: app.js
```node
// Node.js program to demonstrate the   
// console.table() method

// Accessing console module
const console = require('console');

// Calling console.table() 
// fails to parse, so simply 
// print the argument
console.table("arg");

// Blank table
console.table([]);
```

Execute o arquivo app.js usando o seguinte comando:
```
node app.js
```
Saída:
```
arg
┌─────────┐
│ (index) │
├─────────┤
└─────────┘
```

Observação: o programa acima será compilado e executado usando o comando node filename.js. Referência: https://nodejs.org/api/console.html#console_console_table_tabulardata_properties
