O método console.countReset() é uma interface de programação de aplicativo incorporada do módulo de console que é usada para redefinir a contagem do rótulo específico passado a ele como parâmetro. 
Sintaxe:
```
console.countReset( label );
```
Parâmetros: Esse método tem um parâmetro, conforme mencionado acima e descrito abaixo:
label: É um parâmetro opcional que especifica o rótulo cujo contador deve ser redefinido. O valor padrão é "default".
Valor de retorno: Esse método não fornece nenhuma saída, mas redefine o contador para o rótulo especificado. Os exemplos a seguir ilustram o uso do método console.countReset() no Node.js: 
### Exemplo 1:

```node
// Node.js program to demonstrate the 
// console.countReset() method

// Accessing console module
const console = require('console');
 
// Calling console.count() method 
console.count("a");
console.count("b");
console.count("a");
console.count("a");
console.count("a");
console.count("b");
 
// Resetting counter
console.countReset("a");
console.countReset("b");
 
console.count("a");
console.count("b");
```
Saída:
```
a: 1
b: 1
a: 2
a: 3
a: 4
b: 2
a: 1
b: 1
```

### Exemplo 2:
```node
// Node.js program to demonstrate the 
// console.countReset() method

// Accessing console module
const console = require('console');

// Calling console.count() method
// with no parameter to count
// default label
console.count();
console.count("a");
console.count("b");
console.count("a");
console.count("a");
console.count();
console.count();

// Resetting counter
console.countReset();
console.countReset("a");
console.countReset("b");

console.count();
console.count("a");
console.count("b");
```
Saída:
```
default: 1
a: 1
b: 1
a: 2
a: 3
default: 2
default: 3
default: 1
a: 1
b: 1
```

Observação: O programa acima será compilado e executado usando o comando node filename.js. Referência: https://nodejs.org/api/console.html#console_console_countreset_label
