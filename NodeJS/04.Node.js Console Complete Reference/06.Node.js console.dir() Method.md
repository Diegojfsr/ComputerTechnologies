O método console.dir() é usado para obter a lista de propriedades de objeto de um objeto especificado. Essas propriedades de objeto também têm objetos filhos, dos quais você pode inspecionar para obter mais informações. 
Sintaxe:
```
console.dir( _object_ )
```

Parâmetros: Esse método aceita um único parâmetro que contém o elemento do objeto. 
### Exemplo 1:
```html
<!DOCTYPE html>
<html>

<head>
    <style>
        h1 {
            color:green;
        }
        body {
            text-align:center;
        }
    </style>
</head>

<body>

    <h1>GeeksforGeeks</h1>
    
    <h2>console.dir() Method</h2>
    
    <h3>
        Open console using F12 or Ctrl+Shift+I
    <h3>

    <script>
        var geek = { 
            course : "DSA", 
            price : "5000" 
        };
        
        console.dir(geek);
    </script>
</body>

</html>
```
