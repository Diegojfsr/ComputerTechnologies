O método console.clear() é usado para limpar o stdout; quando o stdout for um TTY (Teletype), ou seja, um terminal, ele tentará limpar o TTY. Quando o stdout não é um TTY, esse método não faz nada. O console.clear() funcionará de forma diferente em diferentes sistemas operacionais e tipos de terminal. Nos sistemas operacionais Linux, console.clear() funciona como o comando clear shell no terminal. No Windows, console.clear() limpará a janela de visualização do terminal atual para o binário do Node.js. 
Sintaxe:
```
console.clear()
```
Parâmetros: Esse método não aceita nenhum parâmetro. Os programas abaixo ilustram o método console.clear() no Node.js: Neste exemplo, primeiro escrevemos o comando node.js no terminal e iniciamos o node.js e, em seguida, escrevemos o comando básico.
  
![](https://media.geeksforgeeks.org/wp-content/uploads/20200107124443/console.clear_.png)

Após console.clear(), o terminal será limpo da mesma forma que o comando clear faz no terminal
  
![](https://media.geeksforgeeks.org/wp-content/uploads/20200107124445/console.clear1_.png)

Para sair do terminal do Node.js, pressione Ctrl + C duas vezes ou use o comando .exit. 
### Exemplo:
```node
// Node.js program to demonstrate the  
// Buffer.clear() Method

// Both two lines will not display
// the result on screen
console.log("GeeksforGeeks");
console.log("A computer science portal");

// Clear the previous screen
console.clear();

// Display the content
console.log("Clear the console screen");
```
