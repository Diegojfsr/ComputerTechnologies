O método console.debug() é uma interface de programação de aplicativo incorporada do módulo de console que é usada para imprimir mensagens no stdout em uma nova linha. Semelhante ao método console.log().
Sintaxe:
```
console.debug(data, args);
```

Parâmetros: Esse método tem dois parâmetros, conforme mencionado acima e descrito abaixo:
data: Esse parâmetro especifica os dados a serem impressos.
args: É um parâmetro opcional que especifica os parâmetros a serem passados como valores de substituição nas mensagens passadas para data. Todos os args passados são enviados para util.format().
Valor de retorno: Esse método não retorna nada, mas imprime a mensagem formatada no stdout em uma nova linha.

### Exemplo 1:
O exemplo abaixo ilustra o uso de um método console.debug() no Node.js:
Nome do arquivo: app.js
```node
// Accessing console module
const console = require('console');

// Calling console.debug()
console.debug("This is a sample debug message!");
console.debug("Sample debug message with args: %d", 39);
```

Execute o arquivo app.js usando o seguinte comando:
```
node app.js
```
Saída:
```
This is a sample debug message!
Sample debug message with args: 39
```

### Exemplo 2: 
O exemplo abaixo ilustra o uso de um método console.debug() no Node.js:
Nome do arquivo: app.js
```node
// Accessing console module
const console = require('console');

// Calling console.debug()
console.debug("This is a %s",
    " sample debug message!");
console.debug("Sample debug message"
    + " with args: %d", 34);
console.debug("Debug message: Warning "
    + "at function %s: line number %d ",
    "ff()", 96)

let isDebugMode = true;
console.custom_debug = function (message) {
    if (isDebugMode) {
        console.log(message);
    }
}

console.custom_debug("Custom debug message");
```

Execute o arquivo app.js usando o seguinte comando:
```
node app.js
```
Saída:
```
This is a  sample debug message!
Sample debug message with args: 34
Debug message: Warning at function ff(): line number 96
Custom debug message
```

Observação: o programa acima será compilado e executado usando o comando node filename.js.
Referência: https://nodejs.org/api/console.html#console_console_debug_data_args
