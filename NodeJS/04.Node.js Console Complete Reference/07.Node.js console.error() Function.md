A função console.error() da classe console do Node.js é usada para exibir uma mensagem de erro no console. Ela imprime no stderr com uma nova linha.
Sintaxe:
```
console.error([data][, ...args])
```

Parâmetro: Essa função pode conter vários parâmetros. O primeiro parâmetro é usado para a mensagem principal e os outros parâmetros são usados para valores de substituição.
Valor de retorno: A função retorna uma mensagem de erro.
Os programas abaixo demonstram o funcionamento da função console.error():

### Programa 1:
```node
// Store number to variable
num = 20

// Check condition
if (num < 100) {
    console.log("Enter number greater than 100");
}
else {
    console.error("correct choice");
}
```
Saída:
```
 Enter number greater than 100
```

### Programa 2:
```node
// Store number to variable
x = 20;
y = 50;

// Check condition
if (x > y) {
    console.error('%d is greater than %d', x, y);
}
else {
    console.error('%d is less than or equal to %d', x, y);
}
```
Saída:
```
20 is less than or equal to 50
```
