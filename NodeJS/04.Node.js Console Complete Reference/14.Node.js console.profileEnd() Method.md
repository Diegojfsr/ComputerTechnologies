O módulo de console fornece um console de depuração simples que é fornecido por navegadores da Web que exportam dois componentes específicos:
A classe do console pode ser usada para gravar em qualquer fluxo do Node.js. Exemplo: console.log(), console.error(), etc.
Um console global pode ser usado sem importar um console. Exemplo: process.stdout, process.stderr etc.

O método console.profileEnd() (adicionado na versão 8.0.0) é uma interface de programação de aplicativo incorporada do módulo "console" que não exibe nada, a menos que seja usado no inspetor. Na verdade, ele interrompe a sessão de criação de perfil de CPU JavaScript atual, se tiver sido iniciada, e imprime o relatório no painel Perfis do inspetor e, se esse método for chamado sem um rótulo, o perfil iniciado mais recentemente será interrompido.
Observação: Os métodos do console global não são nem consistentemente síncronos nem consistentemente assíncronos.
Sintaxe:
```
console.profileEnd([label])
```

Parâmetros: Essa função aceita um único parâmetro, conforme mencionado acima e descrito abaixo:
label `<string>`: Aceita o nome do rótulo que será usado posteriormente no inspetor.
Valor de retorno: Não imprime nada no console; em vez disso, finaliza/termina um perfil de CPU JavaScript no Inspector.
Os exemplos abaixo ilustram o uso de um método console.profileEnd() no Node.js.
### Exemplo 1: Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// console.profileEnd() Method

// Starting MyLabel console profile
console.profile('MyLabel');

// Doing some task
for (let i = 0; i < 4; i++) {
    // Printing some task
    console.log('Doing task no:', i);
}

// Finishing MyLabel profile
console.profileEnd('MyLabel');
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```

Saída no console:
```
Doing task no: 0
Doing task no: 1
Doing task no: 2
Doing task no: 3
```

### Exemplo 2: Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// console.profileEnd() Method

// New profile function
function newProfile(callback) {
    try {
        // Do some task
        for (let i = 1; i < 4; i++) {
            console.log('Working on task:', i);
            callback();
        }
    } catch {
        // Prints if there is error
        console.error('error occurred');
    }
}

// Starting newProfile() console profile
console.profile("newProfile()");

// Calling newprofile()
newProfile(function alfa() {
    // Finishing profile
    console.profileEnd();
});
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```

Saída no console:
```
Working on task: 1
Working on task: 2
Working on task: 3
```
