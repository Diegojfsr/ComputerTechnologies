O método crypto.generateKeyPair() é uma interface de programação de aplicativo embutida do módulo crypto que é usada para gerar um novo par de chaves assimétricas do tipo especificado. Por exemplo, os tipos de chave compatíveis no momento são RSA, DSA, EC, Ed25519, Ed448, X25519, X448 e DH. Além disso, se a opção publicKeyEncoding ou privateKeyEncoding for declarada aqui, essa função agirá como se keyObject.export() tivesse sido chamada em sua saída. Caso contrário, a parte específica da chave é retornada como um KeyObject. No entanto, sugere-se codificar as chaves públicas como "spki" e as chaves privadas como "pkcs8" com criptografia para armazenamento de longo prazo. 
Sintaxe:
```
crypto.generateKeyPair( type, options, callback )
```

Parâmetros: Esse método aceita três parâmetros, conforme mencionado acima e descrito abaixo:
type (tipo): Contém uma cadeia de caracteres e deve incluir um ou mais dos seguintes algoritmos: 'rsa', 'dsa', 'ec', 'ed25519', 'ed448', 'x25519', 'x448' ou 'dh'.
options: é do tipo objeto. Pode conter os seguintes parâmetros:
modulusLength: Contém um número. É o tamanho da chave em bits e é aplicável somente aos algoritmos RSA e DSA.
publicExponent: Contém um número. É o expoente público do algoritmo RSA. Seu valor padrão é 0x10001.
divisorLength: Contém um número. É o tamanho de q em bits do algoritmo DSA.
namedCurve: Contém uma cadeia de caracteres. É o nome da curva a ser usada no algoritmo EC.
prime: contém um buffer. É o parâmetro prime do algoritmo DH.
primeLength: Contém um número. É o comprimento principal do algoritmo DH em bits.
generator: Contém um número. É o gerador personalizado do algoritmo DH. Seu valor padrão é 2.
groupName: Contém uma cadeia de caracteres. É o nome do grupo Diffie-Hellman do algoritmo DH.
publicKeyEncoding: Contém uma cadeia de caracteres.
privateKeyEncoding: Contém um objeto.

callback: É uma função, com parâmetros publicKey, privateKey e err.
err: contém um erro.
publicKey: Contém uma cadeia de caracteres, um buffer ou um KeyObject.
privateKey: Contém uma cadeia de caracteres, um buffer ou um KeyObject.
Valor de retorno: Retorna um novo par de chaves assimétricas do tipo fornecido. Os exemplos a seguir ilustram o uso do método crypto.generateKeyPair() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the
// crypto.generateKeyPair() method

// Including generateKeyPair from crypto module
const { generateKeyPair } = require('crypto');

// Calling generateKeyPair() method
// with its parameters
generateKeyPair('rsa', {
  modulusLength: 530,    // options
  publicExponent: 0x10101,
  publicKeyEncoding: {
    type: 'pkcs1',
    format: 'der'
  },
  privateKeyEncoding: {
    type: 'pkcs8',
    format: 'der',
    cipher: 'aes-192-cbc',
    passphrase: 'GeeksforGeeks is a CS-Portal!'
  }
}, (err, publicKey, privateKey) => { // Callback function
       if(!err)
       {
         // Prints new asymmetric key pair
         console.log("Public Key is : ", publicKey);
         console.log();
         console.log("Private Key is: ", privateKey);
       }
       else
       {
         // Prints error
         console.log("Errr is: ", err);
       }
       
  });
```

### Exemplo 2:
```node
// Node.js program to demonstrate the
// crypto.generateKeyPair() method

// Including generateKeyPair from crypto module
const { generateKeyPair } = require('crypto');

// Calling generateKeyPair() method
// with its parameters
generateKeyPair('ec', {
  namedCurve: 'secp256k1',   // Options
  publicKeyEncoding: {
    type: 'spki',
    format: 'der'
  },
  privateKeyEncoding: {
    type: 'pkcs8',
    format: 'der'
  }
},
 (err, publicKey, privateKey) => { // Callback function
       if(!err)
       {
         // Prints new asymmetric key
         // pair after encoding
         console.log("Public Key is: ",
                  publicKey.toString('hex'));
         console.log();
         console.log("Private Key is: ",
                 privateKey.toString('hex'));
       }
       else
       {
         // Prints error
         console.log("Errr is: ", err);
       }
       
  });
```
