O método crypto.createSign() é usado para criar um objeto Sign que usa o algoritmo indicado. Além disso, você pode usar o método crypto.getHashes() para acessar os nomes de todos os algoritmos de resumo disponíveis. 
Sintaxe:
```
crypto.createSign( algorithm, options )
```

Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito a seguir:
algorithm: É um valor do tipo string. Uma instância de sinal pode ser criada aplicando-se o nome de um algoritmo de assinatura, como "RSA-SHA256", no lugar de um algoritmo de resumo.
options: É um parâmetro opcional usado para controlar o comportamento do fluxo. Ele retorna um objeto.

Valor de retorno: Retorna o objeto Sign. Os exemplos abaixo ilustram o uso do método crypto.createSign() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the 
// crypto.createSign() method

// Including crypto module
const crypto = require('crypto');

// Defining the algorithm to be used
const algo = 'RSA-SHA256';

// Creating Sign object
const sign = crypto.createSign(algo);

// Output
console.log(sign);
```

### Exemplo 2:
```node
// Node.js program to demonstrate the 
// crypto.createSign() method

// Including crypto module
const crypto = require('crypto');

// Defining the algorithm to be used
const algo = 'SHA256';

// Creating Sign object
const sign = crypto.createSign(algo);

sign.write('some data to sign');
```
