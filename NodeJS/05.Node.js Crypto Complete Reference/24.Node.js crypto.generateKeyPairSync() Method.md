O método crypto.generateKeyPairSync() é uma interface de programação de aplicativo embutida do módulo crypto que é usada para gerar um novo par de chaves assimétricas do tipo especificado. Por exemplo, os tipos de chave atualmente compatíveis são RSA, DSA, EC, Ed25519, Ed448, X25519, X448 e DH. Além disso, se a opção publicKeyEncoding ou privateKeyEncoding for declarada aqui, essa função agirá como se keyObject.export() tivesse sido chamada em sua saída. Caso contrário, a parte específica da chave é retornada como um KeyObject. No entanto, sugere-se codificar as chaves públicas como 'spki' e as chaves privadas como 'pkcs8' com uma frase secreta forte, a fim de manter a frase secreta. 
Sintaxe:
```
crypto.generateKeyPairSync( type, options )
```

Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito abaixo:
type (tipo): Contém uma cadeia de caracteres e deve incluir um ou mais dos seguintes algoritmos: 'rsa', 'dsa', 'ec', 'ed25519', 'ed448', 'x25519', 'x448' ou 'dh'.
options: É do tipo objeto. Pode conter os seguintes parâmetros:
modulusLength: Contém um número. É o tamanho da chave em bits e é aplicável somente aos algoritmos RSA e DSA.
publicExponent: Contém um número. É o expoente público do algoritmo RSA. Seu valor padrão é 0x10001.
divisorLength: Contém um número. É o tamanho de q em bits do algoritmo DSA.
namedCurve: Contém uma cadeia de caracteres. É o nome da curva a ser usada no algoritmo EC.
prime: contém um buffer. É o parâmetro prime do algoritmo DH.
primeLength: Contém um número. É o comprimento principal do algoritmo DH em bits.
generator: Contém um número. É o gerador personalizado do algoritmo DH. Seu valor padrão é 2.
groupName: Contém uma cadeia de caracteres. É o nome do grupo Diffie-Hellman do algoritmo DH.
publicKeyEncoding: Contém uma cadeia de caracteres.
privateKeyEncoding: Contém um objeto.

Valor de retorno: Retorna um novo par de chaves assimétricas do tipo fornecido, ou seja, retorna um objeto que inclui uma chave privada e uma chave pública que contém a cadeia de caracteres, o buffer e o KeyObject. Os exemplos a seguir ilustram o uso do método crypto.generateKeyPairSync() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the
// crypto.generateKeyPairSync() method

// Including generateKeyPairSync from crypto module
const { generateKeyPairSync } = require('crypto');

// Including publicKey and  privateKey from 
// generateKeyPairSync() method with its 
// parameters
const { publicKey, privateKey } = generateKeyPairSync('ec', {
  namedCurve: 'secp256k1',    // Options
  publicKeyEncoding: {
    type: 'spki',
    format: 'der'
  },
  privateKeyEncoding: {
    type: 'pkcs8',
    format: 'der'
  }
});

// Prints asymmetric key pair
console.log("The public key is: ", publicKey);
console.log();
console.log("The private key is: ", privateKey);
```
