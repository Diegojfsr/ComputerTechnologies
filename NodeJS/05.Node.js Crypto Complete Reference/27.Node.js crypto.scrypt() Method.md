O método crypto.scrypt() é uma interface de programação de aplicativo incorporada do módulo de criptografia que é usada para permitir a implementação de um script assíncrono. Onde scrypt é uma função de derivação de chave baseada em senha. Seu objetivo é ser dispendioso do ponto de vista computacional e de memória. Assim, os ataques de força bruta não são bem-sucedidos.
Sintaxe:
```
crypto.scrypt( password, salt, keylen, options, callback )
```

Parâmetros: Esse método aceita cinco parâmetros, conforme mencionado acima e descrito a seguir:

password: Pode conter dados do tipo string, Buffer, TypedArray ou DataView.
salt: Contém dados do tipo string, Buffer, TypedArray ou DataView. Deve ser o mais exclusivo possível. Além disso, sugere-se que o salt seja aleatório e tenha no mínimo 16 bytes.
keylen: é o comprimento da chave e deve ser um número.
options: É do tipo Object e tem sete parâmetros: cost, blockSize, parallelization, N, r, p e maximum. 
Onde:
cost: é um parâmetro de custo para CPU ou memória. É um número e deve ser uma potência de dois maior, mas maior que um e, por padrão, seu valor é 16384.
blockSize: É o parâmetro para o tamanho do bloco alocado. É um número e o valor padrão é 8.
parallelization: É o parâmetro para Paralelização. É um número e o valor padrão é 1.
N: é um alias para custo. É um número e somente um de ambos pode ser definido.
r: É um alias para blockSize. É um número e somente um de ambos pode ser definido.
p: É um alias para parallelization. É um número e somente um de ambos pode ser definido.
maxmem: É o limite superior da memória a ser usada. É um número e pode ocorrer um erro quando 128 * N * r (aproximadamente) for maior que maxmem. O valor padrão é (32 * 1024 * 1024).

callback É uma função com dois parâmetros: err e chave derivada.
Valor de retorno: Retorna um buffer.
Os exemplos abaixo ilustram o uso do método crypto.scrypt() no Node.js:
### Exemplo 1:
```node
// Node.js program to demonstrate the
// crypto.scrypt() method

// Including crypto module
const crypto = require('crypto');

// Calling scrypt method with some of its parameter
crypto.scrypt('GfG', 'ffdgsg', 32, (err, derivedKey) => {

    if (err) throw err;

    // Prints derived key as buffer
    console.log("The derived key1 is :", derivedKey);
});

// Calling scrypt method with the parameter N
crypto.scrypt('GeeksforGeeks', 'tfytdx', 128,
    { N: 512 }, (err, derivedKey) => {

        if (err) throw err;

        // Prints derived key as buffer
        console.log("The derived key2 is :", derivedKey);
        console.log();
    });
```

### Exemplo 2:
```node
// Node.js program to demonstrate the
// crypto.scrypt() method

// Including crypto module
const crypto = require('crypto');

// Defining salt as typed array
const x = new Uint32Array(7);

// Calling scrypt method with some of its parameter
crypto.scrypt('yytunnd', x, 16, (err, derivedKey) => {

    if (err) throw err;

    // Prints derived key which is encoded
    console.log("The derived key1 is :",
        derivedKey.toString("ascii"));
});

// Defining salt as data view
const y = new DataView(new ArrayBuffer(5));

// Calling scrypt method with the parameter N
crypto.scrypt('oksjdjdn', y, 16, { N: 32 },
    (err, derivedKey) => {

        if (err) throw err;

        // Prints derived key after encoding
        console.log("The derived key2 is :",
            derivedKey.toString("base64"));
        console.log();
    });
```
Saída:
```
The derived key2 is : 6Gu0JKHDSHs0tkTuGYuQ7A==
The derived key1 is : G"@&H 
                           pVCD3                               
                                X%
```
