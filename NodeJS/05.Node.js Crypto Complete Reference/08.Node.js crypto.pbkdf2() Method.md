O método crypto.pbkdf2() fornece uma implementação assíncrona da Função de Derivação de Chave Baseada em Senha 2 (PBKDF2). Além disso, um algoritmo de digestão HMAC específico, definido por digest, é implementado para derivar uma chave com o comprimento de byte necessário (keylen) a partir da senha, do sal e das iterações declaradas. 
Sintaxe:
```
crypto.pbkdf2( password, salt, iterations, keylen, digest, callback )
```

Parâmetros: Esse método aceita seis parâmetros, conforme mencionado acima e descrito abaixo:
password: pode conter dados do tipo string, Buffer, TypedArray ou DataView.
salt: Deve ser o mais exclusivo possível. No entanto, recomenda-se que o salt seja arbitrário e, de qualquer forma, tenha pelo menos 16 bytes de comprimento. É do tipo string, Buffer, TypedArray ou DataView.
iterations: Deve ser um número e deve ser definido como o mais alto possível. Portanto, quanto maior for o número de iterações, mais segura será a chave derivada, mas, nesse caso, leva mais tempo para ser concluída. É do tipo número.
keylen: é a chave com o comprimento de byte necessário e é do tipo número.
digest: São algoritmos de digestão do tipo string.
callback: É uma função com dois parâmetros, a saber, err e derivedKey.

Tipo de retorno: Ele retorna a chave derivada baseada em senha. O exemplo abaixo ilustra o uso do método crypto.pbkdf2() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the 
// crypto.pbkdf2() method

// Including crypto module
const crypto = require('crypto');

// Implementing pbkdf2 with all its parameters
crypto.pbkdf2('secret', 'salt', 100000, 64,
         'sha512', (err, derivedKey) => {

  if (err) throw err;

  // Prints derivedKey
  console.log(derivedKey.toString('hex'));
});
```
