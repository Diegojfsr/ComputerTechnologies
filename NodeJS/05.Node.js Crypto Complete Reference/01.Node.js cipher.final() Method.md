O método cipher.final() no Node.js é usado para sinalizar ao objeto cipher que o processo de criptografia ou descriptografia está concluído. Esse método deve ser chamado depois que todos os dados tiverem sido passados para o objeto de criptografia usando o método cipher.update().
O método cipher.final() retorna os dados criptografados ou descriptografados restantes como um objeto Buffer. Se o parâmetro outputEncoding tiver sido especificado ao criar o objeto cipher, o Buffer retornado será automaticamente codificado usando a codificação especificada.
Sintaxe:
```
const cipher.final([outputEncoding])
```

Parâmetros: Esse método usa a codificação de saída como parâmetro.
Valor de retorno: Esse método retorna o objeto do buffer que contém o valor da cifra.
### Exemplo 1: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// cipher.final() method

// Importing crypto module
const crypto = require('crypto');

// Creating and initializing algorithm and password
const algorithm = 'aes-192-cbc';
const password = 'Password used to generate key';

// Getting key for the cipher object
const key = crypto.scryptSync(password, 'salt', 24);

// Creating and initializing the static iv
const iv = Buffer.alloc(16, 0);

// Creating and initializing the cipher object
const cipher = crypto.createCipheriv(algorithm, key, iv);

// Getting buffer value 
// by using final() method
let value = cipher.final('hex');

// Display the result
console.log("buffer :- " + value);
```
Saída:
```
buffer :- b9be42878310d599e4e49e040d1badb9
```

### Exemplo 2: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// cipher.final() method

// Importing crypto module
const crypto = require('crypto');

// Creating and initializing algorithm and password
const algorithm = 'aes-192-cbc';
const password = 'Password used to generate key';

// Getting key for cipher object
crypto.scrypt(password, 'salt', 24,
    { N: 512 }, (err, key) => {

        if (err) throw err;

        // Creating and initializing the static iv
        const iv = Buffer.alloc(16, 0);

        // Creating and initializing the cipher object
        const cipher = crypto
            .createCipheriv(algorithm, key, iv);

        // Getting buffer value 
        // by using final() method
        let value = cipher.final('hex');

        // Display the result
        console.log("buffer :- " + value);
    });
```
Saída:
```
buffer :- 726cccfc7d80ca473d8d4de1a0a42675
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```
