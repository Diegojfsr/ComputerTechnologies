O método crypto.createVerify() é usado para criar um objeto Verify que usa o algoritmo declarado. Além disso, você pode usar crypto.getHashes() para acessar os nomes de todos os algoritmos de assinatura disponíveis. 
Sintaxe:
```
crypto.createVerify( algorithm, options )
```

Parâmetros: Esse método aceita dois parâmetros, conforme mencionado acima e descrito a seguir:
algorithm: É um valor do tipo string. Uma instância de sinal pode ser criada aplicando-se o nome de um algoritmo de assinatura, como "RSA-SHA256", no lugar de um algoritmo de resumo.
options: É um parâmetro opcional usado para controlar o comportamento do fluxo. Ele retorna um objeto.
Valor de retorno: Retorna o objeto Verify. Os exemplos a seguir ilustram o uso do método crypto.createVerify() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the 
// crypto.createVerify() method

// Including crypto module
const crypto = require('crypto');

// Creating verify object with its algo
const verify = crypto.createVerify('SHA256');

// Returns the 'Verify' object
console.log(verify);
```
