O método crypto.createHmac() é usado para criar um objeto Hmac que usa o "algoritmo" e a "chave" declarados.
Sintaxe:
```
crypto.createHmac( algorithm, key, options )
```

Parâmetros: Esse método aceita três parâmetros, conforme mencionado acima e descrito a seguir:
Algoritmo: Depende dos algoritmos acessíveis que são favorecidos pela versão do OpenSSL na plataforma. Ele retorna uma cadeia de caracteres. Os exemplos são sha256, sha512, etc.
key: é a chave HMAC usada para criar o hash HMAC criptográfico. Retorna string, Buffer, TypedArray, DataView ou KeyObject. E, se for um KeyObject, seu tipo deverá ser secret.
options: É um parâmetro opcional e é usado para controlar o comportamento do fluxo. Ele retorna um objeto.
Tipo de retorno: Retorna um objeto Hmac.

Recursos
Gera um hash exclusivo com base no conteúdo e em uma chave secreta.
Oferece suporte a vários algoritmos criptográficos, como "sha256", "sha1", "md5" etc.
Pode ser usado com fluxos para processar grandes quantidades de dados.
Os exemplos abaixo ilustram o uso do método crypto.createHmac() no Node.js:

### Exemplo 1: 
Este exemplo demonstra o uso do método crypto.createHmac() para gerar um hash HMAC da cadeia de caracteres "GeeksforGeeks" usando o algoritmo SHA-256 e uma chave secreta e, em seguida, gerando o hash em formato hexadecimal.

```node
// Node.js program to demonstrate the     
// crypto.createHmac() method

// Includes crypto module
const crypto = require('crypto');

// Defining key
const secret = 'GfG';

// Calling createHmac method
const hash = crypto.createHmac('sha256', secret)
					.update('GeeksforGeeks')  // updating data
                    .digest('hex');           // Encoding to be used

// Displays output
console.log(hash);
```
Saída:
```
a08116905e92633e4f30eefd1276206b259305c8783642fc5b7f51c089187939
```

### Exemplo 2: 
Este exemplo demonstra o uso do método crypto.createHmac() para gerar um hash HMAC do conteúdo do arquivo atual, lido por meio de um fluxo e, em seguida, gera o hash junto com o nome do arquivo.

```node
// Node.js program to demonstrate the	 
// crypto.createHmac() method

// Defining myfile
const myfile = process.argv[1];

// Includes crypto and fs module
const crypto = require('crypto');
const fs = require('fs');

// Creating Hmac 
const creathmac = crypto.createHmac('sha1', 'CS-Portal!');

// Creating read stream
const readfile = fs.createReadStream(myfile);

readfile.on('readable', () => {

    // Calling read method to read data
    const data = readfile.read();
    if (data) {

        // Updating
        creathmac.update(data);
    } else {
        // Encoding and displaying filename
        console.log("The hmac object returns:", 
        `${creathmac.digest('hex')} ${myfile}`);
    }
});

console.log("Program done!");
console.log();
```
Saída:
```
Program done!
The hmac object returns: 4605d44703c2620fc2574c9a9216bd3267457324 /run_dir/interp.js
```

### Resumo
O método crypto.createHmac() do Node.js é uma ferramenta avançada para gerar HMACs, garantindo a integridade e a autenticidade dos dados. Ele oferece suporte a vários algoritmos e se integra perfeitamente a outros módulos do Node.js, o que o torna uma opção versátil para o tratamento seguro de dados em seus aplicativos.
