O método cipher.update() é uma interface de programação de aplicativo embutida da classe Cipher no módulo de criptografia, que é usada para atualizar a cifra com dados de acordo com o formato de codificação fornecido.
Sintaxe:
```
const cipher.update(data[, inputEncoding][, outputEncoding])
```

Parâmetros: Esse método recebe o seguinte parâmetro:
data: É usado para atualizar a cifra por meio de novo conteúdo.
inputEncoding: Formato de codificação de entrada.
outputEncoding: Formato de codificação de saída.
Valor de retorno: Esse método retorna o objeto do buffer que contém o valor da cifra.
### Exemplo 1: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// cipher.update() method

// Importing crypto module
const crypto = require('crypto');

// Creating and initializing algorithm and password
const algorithm = 'aes-192-cbc';
const password = 'Password used to generate key';

// Getting key for the cipher object
const key = crypto.scryptSync(password, 'salt', 24);

// Creating and initializing the static iv
const iv = Buffer.alloc(16, 0);

// Creating and initializing the cipher object
const cipher = crypto.createCipheriv(algorithm, key, iv);

// Updating the cipher with the data
// by using update() method
let encrypted = cipher.update(
    'some clear text data', 'utf8', 'hex');

// Getting the buffer data of cipher 
encrypted += cipher.final('hex');

// Display the result
console.log(encrypted);
```
Saída:
```
e5f79c5915c02171eec6b212d5520d44480993d7d622a7c4c2da32f6efda0ffa
```

### Exemplo 2: 
Nome do arquivo: index.js
```node
// Node.js program to demonstrate the
// cipher.update() method

// Importing crypto module
const crypto = require('crypto');

// Creating and initializing algorithm and password
const algorithm = 'aes-192-cbc';
const password = 'Password used to generate key';

// Getting key for cipher object
crypto.scrypt(password, 'salt', 24,
    { N: 512 }, (err, key) => {
        if (err) throw err;

        // Creating and initializing the static iv
        const iv = Buffer.alloc(16, 0);

        // Creating and initializing the cipher object
        const cipher = crypto
            .createCipheriv(algorithm, key, iv);

        // Updating the cipher with the data
        // by using update() method
        let encrypted = cipher.update(
            'some clear text data', 'utf8', 'hex');

        // Getting the buffer data of cipher  
        encrypted += cipher.final('hex');

        // Display the result
        console.log(encrypted);
    });
```
Saída:
```
5850288b1848440f0c410400403f7b456293229b5231c17d2b83b602f252714b
```

Execute o arquivo index.js usando o seguinte comando:
```
node index.js
```
