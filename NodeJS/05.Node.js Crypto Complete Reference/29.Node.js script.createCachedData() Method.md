O método script.createCachedData() é uma interface de programação de aplicativo incorporada do módulo de script que é usada para criar um cache de código que pode ser usado com a opção cachedData do construtor de script. Ele pode ser chamado a qualquer momento e qualquer número de vezes.
Sintaxe:
```
script.createCachedData()
```

Parâmetros: Esse método não aceita nenhum parâmetro.
Valor de retorno: Retorna o buffer.
Os exemplos abaixo ilustram o uso do método script.createCachedData() no Node.js:
### Exemplo 1:
```node
// Node.js program to demonstrate the     
// script.createCachedData() method

// Including vm module
const vm = require("vm");

// Constructing script and defining a
// function add inside it
const script = new vm.Script(`

function add(a, b) {
  return a + b;
}

const x = add(1, 2);
`);

// Calling createCachedData without caching
// the variable x used above
const cacheWithoutx = script.createCachedData();
console.log(cacheWithoutx);
```


### Exemplo 2:
```node
// Node.js program to demonstrate the     
// script.createCachedData() method

// Including vm module
const vm = require("vm");

// Constructing script and defining a
// function add inside it
const script = new vm.Script(`

function add(a, b) {
  return a + b;
}

const x = add(1, 2);
`);

// Calling runInThisContext method
script.runInThisContext();

// Calling createCachedData with caching
// the variable x used above
const cacheWithx = script.createCachedData();
console.log(cacheWithx);
```
