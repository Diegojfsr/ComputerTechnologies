O método crypto.createECDH() é uma interface de programação de aplicativo embutida do módulo crypto que é usada para criar um objeto de troca de chaves Elliptic Curve Diffie-Hellman (ECDH) com a ajuda de uma curva predefinida que é definida pela string curveName. Além disso, você pode usar o método crypto.getCurves() para retornar a lista de nomes de curvas disponíveis. 
Sintaxe:
```
crypto.createECDH( curveName )
```

Parâmetros: Esse método aceita um único parâmetro curveName, que é do tipo string. Valor de retorno: Retorna o objeto de troca de chaves ECDH. Os exemplos abaixo ilustram o uso do método crypto.createECDH() no Node.js: 
### Exemplo 1:
```node
// Node.js program to demonstrate the 
// crypto.createECDH() method

// Including crypto module
const crypto = require('crypto');

// Creating ECDH with curve name
const curv = crypto.createECDH('secp521r1');

// Prints keys
console.log(curv.generateKeys());
```
Saída:
```
<Buffer 04 01 0a cd d0 94 80 31 e8 ... >
```

### Exemplo 2:
```node
// Node.js program to demonstrate the 
// crypto.createECDH() method

// Including crypto module
const crypto = require('crypto');

// Creating ECDH with curve name
const curv = crypto.createECDH('secp521r1');
curv.generateKeys();

// Prints Public key
console.log("Public Key: ", curv.getPublicKey());

// Prints Private Key
console.log("Private Key :", curv.getPrivateKey());
```
Saída:
```
Public Key: <Buffer 04 01 68 25 14 c8 ... >
Private Key : <Buffer 01 7a ab 4d 71 60 ... >
```
