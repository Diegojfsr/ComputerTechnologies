O método crypto.pbkdf2Sync() fornece uma implementação síncrona da função de derivação de chave baseada em senha 2, ou seja, (PBKDF2). Além disso, um algoritmo de digestão HMAC específico, definido por digest, é implementado para derivar uma chave com o comprimento de byte necessário (keylen) a partir da senha, do sal e das iterações declaradas.
Sintaxe:
```
crypto.pbkdf2Sync( password, salt, iterations, keylen, digest )
```

Parâmetros: Esse método aceita cinco parâmetros, conforme mencionado acima e descrito abaixo:
password: É do tipo string, Buffer, TypedArray ou DataView.
salt: Deve ser o mais exclusivo possível. No entanto, é recomendável que o salt seja arbitrário e, de qualquer forma, tenha pelo menos 16 bytes de comprimento. É do tipo string, Buffer, TypedArray ou DataView.
iterations: Deve ser um número e deve ser definido como o mais alto possível. Portanto, quanto maior for o número de iterações, mais segura será a chave derivada, mas, nesse caso, leva mais tempo para ser concluída. É do tipo número.
keylen: é a chave do comprimento de byte necessário e é do tipo número.
digest: É um algoritmo de digestão do tipo string.

Tipo de retorno: Ele retorna a chave derivada como buffer. Os exemplos abaixo ilustram o uso do método crypto.pbkdf2Sync() no Node.js:
### Exemplo 1:
```node
// Node.js program to demonstrate the 
// crypto.pbkdf2Sync() method

// Including crypto module
const crypto = require('crypto');

// Implementing pbkdf2Sync
const key = crypto.pbkdf2Sync('secret',
           'salt', 2000, 64, 'sha512');

// Prints buffer
console.log(key);
```

```

d7 8e 01 c9 40 d7 84 63 5e 24 ef 71 0f 91 83 bb 6d 03 bd

```
